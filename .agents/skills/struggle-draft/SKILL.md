# 고군분투기(Struggle) 드래프트 작성 워크플로우 (`/struggle-draft`)

`_posts/2026-07-31-struggle-69.markdown` 포맷과 `CLAUDE.md` 규칙에 맞춰 고군분투기 후기 포스트 드래프트를 생성·수정하고 Git 브랜치 및 이미지 폴더를 준비하는 절차입니다.
(원본 이미지 압축 및 최적화는 별도 스킬인 `/compress-images`를 사용합니다.)

## 2. Git 브랜치 및 이미지 폴더 생성

1. **브랜치 생성 (`feature/struggle-N`)**:
   - 최신 `master`를 기준으로 `feature/struggle-<N>` 브랜치를 생성(이미 있으면 체크아웃)합니다:
     ```bash
     git checkout master && git checkout -b feature/struggle-<N>
     ```
2. **이미지 디렉토리 생성 (`img/struggle/N/`)**:
   - `mkdir -p img/struggle/<N>` 명령으로 해당 회차의 이미지 폴더를 생성합니다.

## 3. 포스트 드래프트 작성 (`_posts/YYYY-MM-DD-struggle-N.markdown`)

파일명은 개최일(`YYYY-MM-DD`)을 기준으로 `_posts/YYYY-MM-DD-struggle-N.markdown`으로 생성합니다.
`_posts/2026-07-31-struggle-69.markdown`와 동일한 구조를 따릅니다:

```markdown
---
author: kodeveloper
date: YYYY-MM-DD
layout: post
title: 제N차 고군분투기
categories: [고군분투기]
tags: [영문 토픽 키워드 1, 영문 토픽 키워드 2, ...]
---

![](/img/struggle/N/title.jpg)

### 일정

제목 : 제N차 Kodeveloper 고군분투기  
일시 : YYYY년MM월DD일(요일) 20시 ~ 22시 (19시 30분부터 접수)  
장소 : <장소명>  
주소 : 〒<우편번호> <주소>

### 발표자
```

### 작성 시 필수 주의사항
- **`tags`**: 발표 제목들에서 핵심 주제를 뽑아 영문 키워드 배열(예: `[AI Agent Security, Real Estate Investment, Critical Thinking]`)로 자동 작성합니다.
- **줄바꿈 공백 2칸 규칙 (`### 일정`)**:
  - `제목`, `일시`, `장소` 줄의 끝에는 **반드시 공백 2칸(`  `)**이 들어가야 단일 줄바꿈(`<br>`)으로 렌더링됩니다 (`주소` 줄은 다음 줄이 빈 줄이므로 불필요).
  - 에디터/툴이 트레일링 공백을 제거할 수 있으므로 파일 생성 후 아래 명령으로 줄 끝 공백 2칸을 보장합니다:
    ```bash
    perl -i -pe 's/\s*$/  \n/ if /^(제목|일시|장소) :/' _posts/YYYY-MM-DD-struggle-N.markdown
    ```
- **발표 자료 링크**:
  - 드래프트 시점에 링크가 없으면 `- 자료(준비중)`으로 작성합니다.
  - 추후 링크가 제공되면 `- [자료](URL)`로 교체합니다 (URL 내 괄호 `(` `)`는 `%28`, `%29`로 인코딩).
- **이미지 압축 연계**:
  - 드래프트 생성 완료 후 사용자에게 `img/struggle/<N>/` 폴더에 넣어야 할 파일명 목록을 안내하고, 원본 이미지를 넣은 뒤 `/compress-images` 스킬을 호출하면 압축이 진행된다고 안내합니다.
